## How to Vet Abyssal Escape 2011x Character Claims

Most bad character information doesn't start as a lie. It starts as a reasonable guess that gets repeated until it sounds official. The fix is a short verification habit you can run in under a minute per claim.

- **Find the earliest mention.** Screenshots get reposted for months; the original post usually has the date and context.
- **Check for developer acknowledgment.** A like, reply, or repost from the official account is stronger than a thousand player comments.
- **Look for footage, not description.** If nobody can show the character in motion, treat the detail as unverified.
- **Watch for version drift.** A detail that was accurate earlier may have been patched out.
- **Separate lore from mechanics.** A character can be real in the story and still not exist as a playable option.

| Claim you'll see | Red flag | Verification step |
|---|---|---|
| "This character has a secret ability" | No clip, no timestamp | Ask for footage from the current build |
| "There's a code for this character" | Vague source, urgency language | Check the official account directly |
| "The roster has twelve characters" | Round number, no list | Count confirmed entries yourself |
| "This name was datamined" | No file, no screenshot | Wait for developer confirmation |
| "This character was removed" | Old footage only | Compare against the newest clips |

## Building a Character Notes Sheet That Actually Helps

Serious players in escape-style games keep notes, and the good ones keep them boring. A single sheet with fixed fields beats a folder of screenshots, because it forces you to record what you actually know rather than what you remember.

| Field | Why it matters | How to fill it |
|---|---|---|
| Name or label | Keeps entries searchable | Use the in-game name; note "unnamed" if there isn't one |
| Role type | Predicts how a round plays out | Pick from survivor, pursuer, support, environmental |
| Confirmation status | Prevents rumor creep | Mark confirmed, footage-only, or unverified |
| Source link | Lets you re-check later | Save the original post, not a repost |
| First seen date | Flags stale entries | Use the date of the earliest reliable mention |
| Open questions | Directs your next test | One line per unknown |

Keep the sheet short. If an entry has more speculation than facts, it belongs in a scratch section, not the main list. Players who maintain this habit report far less confusion when new footage drops, because they can instantly tell whether a "new" character is genuinely new or just a resurfaced rumor from months earlier.
